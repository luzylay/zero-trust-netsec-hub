## Reporting a Vulnerability

The Zero-Trust Network Security Research Hub adheres to coordinated and responsible vulnerability disclosure:

1. **Do not create public GitHub issues** for security vulnerabilities or potential credential leaks.
2. Report vulnerabilities via GitHub's private vulnerability reporting feature under the **Security** tab of this repository.
3. Include detailed steps to reproduce, sample payloads, and expected versus observed behavior.
4. Security triage SLAs:
   - **Acknowledgment:** Within 24 hours.
   - **Remediation & Patching:** Within 72 hours for critical/high vulnerabilities.
